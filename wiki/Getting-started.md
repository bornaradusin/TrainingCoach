# Getting started

1. Install the APK from the newest release on GitHub.
2. Open Training Coach. The **Beginner full body** plan is ready to use. To pick another, go to **Plans**.
3. On **Train**, tap **Start**. The app shows the first exercise, the pin to use and the reps to aim for.
4. After each set, set the reps you did and tap **Log set**. The rest timer starts; when it buzzes, do the next set.
5. Tap **Finish** when you're done. Next time, the plan moves on to its next day, and the app suggests the pin from what you did.

The first time you do an exercise, the app suggests a light pin (pin 2, 9.2 kg). Find a weight you can lift for the target reps with good form, and log that. From then on it suggests the next pin for you.
